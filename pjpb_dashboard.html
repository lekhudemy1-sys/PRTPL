Editable Rules

Quarter Target Qty = this value × days in the quarter (MIS sheet: 15000 × 92)
In Monthly & Quarterly Performance, a quarter below this % is shown in red

How every dashboard value is calculated

Use this list to trace a wrong value. RR = RR Weight (rr_weight), Net = Net wt., Qtr = the selected quarter. "Sum" means the total of the quarter's rakes, unless an area or source is named. Per MT = amount ÷ total RR Weight.

Key Performance (top left card)

  • Per Day Required Rake for Target = sum of each area's "Asking Per Day" from the Target Rake table (Data Entry)
  • Performance on Rake Materialization = total Rake Loaded Till ÷ total Qtr Target × 100
  • Quarter Target Qty = Per Day Quantity target (Formulas) × days in the quarter
  • Achieved Qty = sum of RR Weight; Bal. Qty = Achieved − Target (negative = short, shown red)
  • Per Day Required Qty = (Target − Achieved) ÷ days remaining (0 when the target is already met)
  • Plant End GCV = sum of (RR × Plant End GCV) ÷ sum of RR, only for rakes that have a GCV

Area Targets (Qtr)

  • Target of Qtr = Qtr Target for the area (Data Entry > Target Rake)
  • Rake Loaded Till = count of the area's rakes with Loading Date up to the report date (today if no report date)
  • Balance Rake = Target of Qtr − Rake Loaded Till
  • Asking Per Day = Balance Rake ÷ days from the report date to the quarter end (0 when no days remain)

Weight Variance

  • Avg Variance MT per rake = sum of (RR − Net) ÷ number of rakes that have both weights
  • Variance % = sum of (RR − Net) ÷ sum of Net × 100
  • Area Avg. RR Wt. = sum of RR ÷ number of the area's rakes with an RR Weight; Freight / MT = area Railway Total Freight ÷ area RR

Freight Summary

  • RR Freight Base Value, GST, Total Railway Freight = sums of the same columns; per-MT box = amount ÷ sum of RR
  • Total Railway Penalty = Punitive Sum + EHBC/FAUC/TC/ST group + ENHC + EHBC (see right card)
  • Penalty as % of Total Freight = Total Penalty ÷ Total Railway Freight × 100
  • Expected Freight of the Qtr = Total Railway Freight ÷ days passed in the quarter × total days in the quarter

Rake Performance

  • Per Day Rakes – Achieve = number of rakes ÷ days passed in the quarter; Target = Per Day Required Rake
  • Per Day Quantity – Achieve = sum of RR ÷ days passed; Target = Per Day Quantity target (Formulas)
  • Freight Cost / MT – Achieve = Total Railway Freight ÷ sum of RR; Target = Freight Cost Target (Data Entry)
  • Avg. Net Wt. / Chargeable Wt. / RR Wt. = simple averages; Avg. Loading Time = average of P/T to C/T; Total Rakes Loaded = number of rakes

Railway Freight Penalties

  • Punitive Sum = sum of POL1 + POL2 + POLA + KRBA + LADC + PCLA + DCLA
  • EHBC / FAUC / TC / ST group = sum of SD + SDCC + ST + TC + FAUC; ENHC = sum of ENHC; EHBC = sum of EHBC
  • TOTAL PENALTY = Punitive Sum + EHBC group + ENHC + EHBC; per-MT box = ÷ sum of RR
  • Underload, Overload and CHBL at Punitive Rate = sums of U/L, O/L and CHBL AT PUN RATE (quantities)

Area Wise & Source Wise Performance

  • Each column is one area (TOTAL = all areas). Rakes, RR, Variance, Punitive, EHBC group, ENHC and Total Freight are sums for that area
  • Avg. RR Wt. = sum of RR ÷ rakes with RR; Freight / MT = Total Freight ÷ RR; Avg. Loading = average P/T to C/T
  • Source Wise groups rakes by siding name without the bracket code (BAROUD (BOMK) counts as BAROUD)

Monthly & Quarterly Performance

  • Per Day Qty (month) = sum of RR for the month ÷ days passed in that month; Freight / MT (month) = month freight ÷ month RR
  • Quarterly values use the same formulas across the quarter
  • % = Quarterly Qty ÷ Quarter Target Qty × 100 (capped at 100%; red when below the "Highlight below" value)

Calculated in Data Entry and the database

  • Sick Wagons = Supply Wagons − Load Wagons (blank Load counts as 0, same as the Excel sheet)
  • Punitive Sum (POL1/PO2/POLA/PCLA/DCLA) and EHBC/FAUC/TC/ST are the sums above, per rake
  • Loading Duration = P/T to C/T in minutes (past-midnight loading handled)
  • Railway Total Freight (Data Entry suggestion) = RR Freight Base Value + Punitive Sum + EHBC group + GST + ENHC + EHBC, rounded; you can overwrite it
  • Date of Sample Collection defaults to the Loading Date, as in the sheet
  • A rake is identified by Loading Date + Area + Source + P/T + RR Number, so uploading the same sheet twice updates rakes instead of duplicating them
